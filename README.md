# Ammama's Angadi — Website

This is a simple, fully editable static website.

## Files

- `index.html` — all website content and product cards
- `styles.css` — colours, fonts, layout and responsive design
- `script.js` — WhatsApp button, menu and small interactions
- `assets/logo.png` — your Ammama's Angadi logo

## Before publishing

Open `script.js` and change:
1. `WHATSAPP_NUMBER` to the real business WhatsApp number.
2. Instagram URL if your final Instagram username is different.

Open `index.html` to edit:
- product names
- descriptions
- prices
- brand story
- contact details
- page text

## Free hosting

Recommended: GitHub + Cloudflare Pages.

1. Create a GitHub repository.
2. Upload all files/folders from this project.
3. Create a Cloudflare Pages project connected to that GitHub repository.
4. Set the build type to a static site with no build command.
5. Set the output directory to the project root.
6. Add `ammamasangadi.in` as the custom domain in Cloudflare Pages.
7. Follow the DNS instructions shown by Cloudflare.

No paid website builder is required.
